# UniHub v0.4.45

重做平台管理端的「产品访问与角色」界面。修复前，一组产品角色、允许访问开关和保存操作被放在同一行中，原生 checkbox 又受全局输入框宽度影响被拉伸成长方形，导致文字折行、控件错位。新界面为每个接入产品提供独立卡片：产品名、实例、当前访问状态和授权版本放在卡片头部；访问状态使用独立开关；角色以自适应复选网格呈现，特权角色带明确标记；每张卡片在底部单独保存。平台管理资格的选择项也改为固定尺寸网格，保持禁用和键盘焦点语义。

保存契约保持不变：每个产品仍提交当前角色列表、访问状态和 assignment_version，并通过现有确认弹窗记录操作原因。新增前端回归覆盖卡片布局及保存请求的内容。

本版只涉及管理端 React 页面、CSS 与前端测试。后端服务、OpenAPI 行为、身份、钱包、支付商户配置、费率、数据库结构和既有业务数据均未改变；不新增真实收款、自动迁移或凭据变更。

验证：前端 166 项 Vitest 测试、TypeScript 构建与 Vite 生产构建通过；本地只读预览在桌面、1440px 宽屏和 390px 窄屏核对了卡片、开关、角色网格与保存操作。发布资产校验、GitHub Release 和线上部署读回分别按本次发布收据记录；这些验证不代表生产支付或业务闭环重新验收。
