UniHub v0.2.0 是可组合收费预览版。产品使用统一后台 API 和版本化配置选择收费组件，继续自行实现界面和业务判断。

- `hybrid`：订阅＋每月赠送额度＋加量包；额度用尽不自动扣现金。
- `prepaid`：无需会员，按实际用量直接扣对应账户的 llmrouter 人民币余额。
- `subscription`：纯月/年功能会员，不发模型额度；也可组合会员与现金按量等明确规则。
- 配置、API、SDK、示例界面及资产报表同步；人民币与 CREDIT 不混算。
- 旧订单、已付年度权益、原预占与 UNKNOWN 恢复保留原始条款。

验证通过：真实 PostgreSQL/Formance race 回归、三个模式 HTTP 闭环、27项前端/12项SDK测试、真实 llmrouter 接线与丢失响应重启恢复，以及 MySQL5.7/PostgreSQL9.6历史数据迁移。接线中的身份验证和模型提供方为测试夹具，没有真实收款或模型供应商执行。

附件包含 Linux amd64 服务包、SDK 源码、OpenAPI、带许可和来源清单的 Casdoor 审计构建上下文、发布清单及 SHA256SUMS。服务包包含收费配置工具、示例与 llmrouter 通用桥接补丁。

**启用现金计费前，llmrouter 必须应用随附通用桥接升级，并发布对应 CNY/6 费率。UniHub 发布不会替其它产品自动升级网关。现有产品收费规则保留；真实支付渠道、正式套餐价格与真实模型供应商仍未配置。** SDK 是源码包，未发布至 npm。
