# UniHub v0.4.1

SuperWagie 注册登录与用户中心所需的个人资料沙盒接口。基于线上 v0.4.0 的 `6fc472c4330b433a78aedb8ce6506ab2026992b2`，保留原生计量及全部既有账户、凭据和产品策略。

提供固定登录名查询、昵称修改和清空、私有 PNG/JPEG 头像、旧密码校验后的改密。写入需要 `profile:write`。改密撤销提供方令牌和对应 UniHub 浏览器会话。提供方可能已改密却未完成撤销时返回不确定结果，UniHub 持久化的截止时间仍拒绝旧令牌。传输失败保持 pending 并拒绝该身份的所有 API 会话，直到受控恢复。明确的旧密码错误保留原会话。

UniHub 用户中心接入头像、个人资料、登录安全和产品设置目录。产品设置目录只展示各产品自己的设置范围并提供跳转入口；产品内 API Key、模型、项目、运行时与通知偏好仍由产品管理。

部署必须保留旧发布及已核验备份。migration012 创建头像表，migration013 创建改密不确定结果的令牌截止记录表；二进制回退不回退 schema。产品 scope 变更会关闭 headless gate，必须先完成真实服务审计验收再启用。

当前仍为 sandbox。真实支付、正式价格、模型供应商和模型调用不在本次验收范围。
