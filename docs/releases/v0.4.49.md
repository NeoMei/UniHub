# UniHub v0.4.49

## 用户与产品权限工作台

0.4.49 重做用户管理页面，把身份目录、账户状态和每个产品的角色放在同一工作路径中。左侧目录可直接识别姓名、邮箱、可用/停用状态和当前选择；右侧在账户摘要下方展示产品进入范围与权限卡。

## 交互与安全

- 产品角色按产品分组；管理角色有独立标记，完整权限可展开核对。
- 账号停用通过确认对话框完成，邮箱和统一用户 ID 同时可见。
- 切换用户、付费账户、刷新或离开用户管理页面时，未保存角色会触发明确确认。
- 目录在达到 50 条时显示“最近 50 位”，提示通过关键词缩小范围。

## 发布范围

本次只涉及控制台前端、导航保护、测试与版本元数据。后端、身份、支付、钱包和数据库结构不变。
