# UniHub v0.4.5

天枢式全局导航整理沙盒预览版，基于 v0.4.4。

## 变化

- 控制台顶部增加首页、使用指南、产品矩阵和控制台全局导航。
- 登录后的产品站顶部显示当前用户头像和名称。
- 区分全局产品站导航与控制台工作区导航，避免产品站入口只存在于侧栏。

## 验证

- Web：33/33 tests passed，正式构建通过。
- 登录后控制台与产品站往返导航有回归测试。
- 发布包完成内容与 SHA256 回读校验。

## 边界

当前仍为 sandbox。真实支付、正式价格、模型供应商和模型调用不在本次验收范围。SDK 仍为私有工作区源码包，不发布至 npm。
