# UniHub v0.4.0

UniHub v0.4.0 是与 LLMRouter `metered_v2` 对齐的原生用量计费沙盒预览候选，尚未合并、创建 tag 或发布。

## 主要变化

- 实际供应商 token：对话、Responses、embedding。
- 字符：TTS 按供应商字符回执或明确的最终文本规则计量。
- 音频秒：STT 使用供应商秒数或受限服务端音频测量。
- 图片：按成功图片数与可信 `WxH` 尺寸档计量，未知尺寸保持待核对。
- OCR：按成功请求计量；页数计费尚未启用。
- 视频：按 Sora/Ali 输出秒数或 Kling/Doubao 供应商单位计量；没有明确回执定义的策略在预扣前拒绝。

UniHub 冻结费率、资产、资金来源和调用快照，使用幂等结算与冲突保护。平台资金由 UniHub 托管，不会回退扣除 LLMRouter 本地余额、订阅、token 配额或请求计数。

## 验收边界

本版已通过隔离 PostgreSQL/Formance 的 HTTP/账本测试、CNY/6 与 CREDIT/6 双资产测试、SDK 类型和协议测试，以及 LLMRouter 端到端计量测试。未执行真实供应商调用，不代表真实支付、正式价格、Veo 时长探测或所有供应商组合已上线。遇到缺失、无效、冲突或超出预扣上限的回执会进入待核对，不会猜测费用。

产品直接向统一钱包充值和交互式 MFA 续接仍未开放；保留原有身份与资金范围。SDK 是私有工作区 TypeScript 源码附件，不发布至 npm。现有价格与资金模式不会因升级自动切换，需显式发布 `metered_v2` 费率并升级 LLMRouter 的相应测量适配器。
