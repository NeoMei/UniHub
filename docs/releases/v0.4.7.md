# UniHub v0.4.7

LLMRouter 统一身份与计费预览版。

## 变化

- 公共模型调用的身份、账户、短期产品凭证和计费归 UniHub 所有；LLMRouter 保留独立私有原生运维/兼容边界。
- 版本化 `UsagePolicy.models` 约束产品模型授权；缺省或 null 保留历史目录，显式空数组拒绝所有模型。凭证签发要求每个模型在对应资产上恰有一个已发布费率。
- `GET /v1/products/{product}/model-consistency` 提供只读白名单、已发布费率、缺失/额外/重复模型投影，产品令牌只可读取自身产品并需要 `catalog:read`。
- 支持聊天按请求费率及操作员费率退役。退役仅影响未来选择，在途调用、费率和结算快照保持不变。
- 同步 22 个聊天模型目录、精确有理数 CNY/6 费率与接入验收记录。

## 验证

- 本次发布准备在 `ba92503` 上执行全仓 `go test -race ./... -count=1`，配置隔离 PostgreSQL、真实本地 Formance 及实际 LLMRouter 网关夹具：465 个测试及子测试通过，无测试用例跳过；3 个无测试文件的包单独记为无测试。
- 发布元数据与 OpenAPI 更新后，再次执行同一完整 race 命令通过；Web 36/36、SDK 14/14、正式前端构建、严格 TypeScript 类型检查、`go vet ./...`、OpenAPI YAML/引用检查及版本一致性检查通过。
- 实际 TCP 网关验收覆盖 CREDIT/6 与 CNY/6、结算响应丢失、重启恢复、重复拒绝和原生配额不变；供应商响应及身份校验是受控夹具。
- 既有部署验收记录显示 22 个聊天模型真实供应商调用成功，另有一次 SuperWagie 实际运行时调用；23 次结算精确重算一致。详情见[完整验收记录](../integrations/unihub-owned-llmrouter-acceptance-2026-10-27.md)。该记录对应当时部署，不替代本发布包的部署验收。

## 边界

UniHub 充值与会员资金仍为 **sandbox**；真实供应商调用已经发生并产生上游费用，但真实商户收款/激活、供应商账单对账、打包桌面端点击验收尚未完成。OCR、embedding、rerank、语音、图片和视频不属于这 22 个聊天模型的凭证/验收范围。SDK 保持 `private:true`，不发布至 npm；发布包不包含生产配置或凭据。
