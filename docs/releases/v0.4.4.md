# UniHub v0.4.4

产品文档与登录后控制台入口整理沙盒预览版，基于 v0.4.3。

## 变化

- 使用指南新增 SuperWagie、AgentWiki、llmrouter 三款产品的基础文档。
- 文档包含产品用途、常用路径和 UniHub/产品职责边界。
- 登录后的控制台侧栏新增首页、使用指南和产品矩阵入口。
- 修复登录后只能退出才能回到产品站的问题。

## 验证

- Web：33/33 tests passed，正式构建通过。
- 控制台回到产品站和产品站返回控制台的路径均有回归测试。
- 发布包完成内容与 SHA256 回读校验。

## 边界

当前仍为 sandbox。真实支付、正式价格、模型供应商和模型调用不在本次验收范围。SDK 仍为私有工作区源码包，不发布至 npm。
