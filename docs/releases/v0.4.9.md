# UniHub v0.4.9

统一产品用户基础与可复用源码预览版，配合 LLMRouter `v0.1.0-rc.8`。

## 更新内容

- 产品身份目录独立于计费产品，使用明确的产品/实例声明、默认成员和权限。控制台提供用户查询、产品角色分配及全局启停；用户管理员由 `USER_ADMIN_IDS` 中的不可变中央 UUID 配置，与账单管理员分开。
- 产品角色及全局状态在服务端按当前值校验；角色变更使用版本冲突检测并原子审计，拒绝停用最后一个可用用户管理员。应用入口只展示当前允许访问的产品。
- 独立 Go 用户模块复用 Browser、Client、Service；支持签名验证的 OIDC code/S256 PKCE、中央访问校验及产品资源策略。产品在事务中按 issuer+subject 幂等建立普通业务用户和默认资源，中央角色不会变成原生管理员或永久额度。
- `product_user_init.py` 生成独立 Go 产品与校验过的源码快照、配置示例、产品声明及测试。Notes starter 展示持久化个人笔记本、资源所有权、重复初始化、回滚和进程生命周期；产品自有标准 OIDC 可通过 standalone 接口接入。
- 受保护的客户端登记支持 `browser_sso`、`instance_id` 和 `access:read`。访问/身份接入默认不注册商业产品，独立浏览器 SSO 不隐式开启密码 API、自助注册或管理员授权。
- LLMRouter 使用共享模块完成产品 SSO、普通用户投影、后端身份凭据保管及当前产品角色管理；具体服务端候选内容见 LLMRouter `0.1.0-rc.8` 说明。

## 发布资产

`unihub-userkit-0.4.9-source.tar.gz` 提供经过 Git 跟踪文件白名单筛选的 Go module、starter、初始化/客户端登记工具、公共产品声明示例和接入文档。解压后可以分别在 `packages/userkit-go` 与 `examples/product-users` 执行 `go test -mod=readonly ./...`。校验摘要使用同批次的 `SHA256SUMS`。

初始化工具继续要求经过审查的 Git checkout，使用现有提交及源码摘要校验；解压包不是 Git checkout，不支持直接据此伪造生成器的来源版本。按[接入文档](../integrations/product-user-foundation.md)从固定提交或发布标签生成独立产品。运行包增加 `config/examples/product-user-manifests.json`，由部署者审查并显式配置 `PRODUCT_USER_MANIFESTS_FILE`；发布资产不会自动登记产品或切换线上角色。

TypeScript SDK 保持 `private:true`，不发布 npm；Go 用户模块源码契约仍为 `0.1.0`，没有发布 `packages/userkit-go/v0.x.y` 标签。本仓库尚未声明源码许可，本版不新增许可授权。发布包不包含私有环境、生产凭据或未跟踪文件。

## 验收与边界

[本地验收记录](../integrations/product-user-foundation-acceptance-2026-10-27.md)区分真实本地 Casdoor 浏览器登录、隔离 PostgreSQL/LLMRouter 数据库、生成产品与受控协议回归。已验证同一中央 UUID 的跨产品 SSO、JIT 只初始化一次、资源所有权、普通成员拒绝渠道管理、viewer/operator 分权、现有会话的授权撤回、全局停用、刷新恢复和产品退出。修复后的生命周期、访问型登记及 OIDC discovery 恢复另有自动回归，未将其描述为重复执行真实浏览器矩阵。

Starter 是单进程持久化示例，会话/证明与 OIDC 登录事务在内存；生产 SQL 事务、共享会话及多实例路由仍需产品完成。独立外部 IdP、浏览器自助注册、生产 HTTPS/cookie、发布后真实用户及服务部署需要分别验收。

本次未进行供应商请求、支付或资金入账，不扩大既有 22 个聊天模型验收范围。UniHub 充值与会员资金仍为 **sandbox**；真实商户收款/激活、供应商账单对账及非聊天模态沿用现有未验收边界。
