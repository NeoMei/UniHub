UniHub v0.1.0 是首阶段后台服务预览版，为多个自有产品提供统一身份、账户、充值计费和资源查询。接入产品自己实现界面及业务判断，UniHub 用户中心为可选示例客户端。

- JSON 注册、密码认证、S256 PKCE；独立产品授权范围及账户权限校验。
- 个人/团队账户、成员邀请、产品钱包、订阅、加量包和模型共享额度。
- 余额/权益/调用/用量 API，TypeScript 源码 SDK，通用产品登记工具。
- HTTPS 服务、身份审计脱敏、账务幂等/恢复、备份和隔离恢复验证。

在线服务：[UniHub](https://unihub.quukk.com)，[OpenAPI](https://unihub.quukk.com/openapi.yaml)。

附件包括 Linux amd64 服务部署包、OpenAPI、SDK 源码包、可选的已审计 Casdoor 构建上下文及 SHA256SUMS。服务包的 casdoor-web 是已验证的品牌资源与同源回调补丁；所有应用/数据库/支付密钥必须在目标安装重新生成或使用该安装的受控配置。附件不含服务器私有配置、密码、令牌或用户数据。自定义 Casdoor 上下文保留 Apache-2.0 LICENSE、NOTICE、来源清单和补丁，不包含管理密钥。

当前仍为 **sandbox 测试环境**，没有真实支付渠道、正式套餐价格或真实模型供应商。产品令牌直接充值统一钱包、交互式 MFA 续接、refresh 和服务端 logout 尚未提供。SDK 未发布至 npm，接入产品的 UI 和适配仍由各产品实现。

验证：真实 PostgreSQL/Formance 全仓库 race 回归、SDK 协议与类型检查、公网 JSON/SDK 流程、权限隔离、重启持久化及真实审计/备份恢复检查通过。完整证据与边界见 [验收文档](https://github.com/NeoMei/UniHub/blob/v0.1.0/docs/headless-product-api-validation-2026-10-25.md)。
