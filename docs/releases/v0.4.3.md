# UniHub v0.4.3

产品门户入口整理沙盒预览版，基于 v0.4.2。

## 变化

- 参考 AgentWiki/天枢首页的首屏结构，移除右上角大号登录按钮。
- 登录与进入控制台合并为首屏欢迎卡片中的统一入口，按登录态显示不同文案。
- 顶部导航改为首页、使用指南、产品矩阵和控制台。
- 保留使用指南和产品矩阵独立路径，并验证公网 `/guide` 可访问。

## 验证

- Web：33/33 tests passed，正式构建通过。
- 公网健康检查：`https://unihub.quukk.com/healthz` 返回 `status=ok`。
- 公网首页和 `/guide` 已回读新版入口结构。
- 发布包完成内容与 SHA256 回读校验。
