# UniHub v0.4.6

团队邀请管理闭环沙盒预览版。

## 变化

- 团队成员页显示当前用户收到的待处理邀请，可直接接受。
- owner/admin 可查看团队发出的待处理邀请并撤销；服务端保留角色和当前权限复核。
- owner 可管理非 owner 成员的 `member`、`admin`、`billing_admin` 角色。
- 创建团队或接受邀请后自动切换到新团队。
- OpenAPI、SDK 和账户 API 文档同步增加撤销邀请接口。

## 验证

- Go 全仓测试、`go vet ./...` 通过。
- SDK：14/14 tests passed，严格 TypeScript 类型检查通过。
- OpenAPI YAML 解析、工作区 diff 检查通过。
