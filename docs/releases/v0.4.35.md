# UniHub v0.4.35

用户中心和平台后台对齐托管模型、原生产品计价与统一钱包边界。

- 用户端新增“模型消费”，按来源、产品实例、原付款账户和资产核对预占、原始实扣、返还与待核实状态。
- 消费、充值、概览和趋势覆盖托管模型及原生产品结算；产品与实例授权、成员财务信息隐藏和分页隔离继续生效。
- 账户预算统一约束两条通道的同资产消费，保留 Key 独立限额、旧资产和 UNKNOWN 预占责任。
- 修复后台退款复核状态、日期筛选及导出，增加原账务操作核对；支持按操作配置原生计量费率。
- 三方接入工作台可下载真实脚本准备包，明确公开客户端与私有服务权限、原生 Key 和价格归属。
- 完善密码规则与限流反馈、改密后的当前会话退出，以及支付能力未确认时的购买状态。

本地验证包括前端 93 项、SDK 17 项测试，真实 PostgreSQL/Formance 集成及 race 检查、生产构建，以及桌面/平板/手机的只读样例预览和接入准备包下载。独立审查发现的支付回执标识与 UNKNOWN 退款历史实扣两项问题均已修复并回归。

中央真实收款保持 sandbox 或未配置；原生产品可信支付回执通道是独立能力。此次不迁移身份或余额、不切换原产品计价模式，也不发布 npm 包或容器镜像。5 项依赖外部网关/跨仓环境的验收未执行；发布与部署不代表真实支付、供应商调用或全部跨产品业务验收完成。
