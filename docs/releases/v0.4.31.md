# UniHub v0.4.31

## 模型发现与一键配置前置能力

- 新增受控账户模型发现接口：SuperWagie 使用已登录的产品会话读取当前账户允许的模型能力。
- 新增 OpenAI 兼容的 `GET /v1/models`：持久化 UniHub API key 只能看到其绑定产品、实例、账户、模型白名单、有效期和已发布费率共同允许的模型。
- 返回模型操作、输入/输出模态、上下文、最大输出、探测标记和费率标识；不返回 bearer、provider secret 或内部凭据。
- 所有发现请求在返回目录前重新校验用户状态、账户角色、产品实例、资金资产、key 撤销与有效期。
- SuperWagie 可据此执行模型发现、受限 key 配置和逐项联通测试。

资金保持 sandbox 或未配置状态，本版不代表真实支付已启用。
