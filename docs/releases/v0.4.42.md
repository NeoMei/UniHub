# UniHub v0.4.42

知识任务使用厂商模型标识 `text-embedding-v4`，新任务不再接受 `unihub-text-embedding-v4` 别名。该接口继续校验原有任务凭证、产品访问令牌、成员资格和计费权限。

平台故障豁免增加 SuperWagie 原生报价校验，核对付款产品、模型、wire operation、报价摘要、计费转换和原预留金额后才能处理。供应商用量与未决成本状态保留。

已产生的历史调用保留原模型记录，历史结果读取继续受现行访问权限约束。钱包、计价、知识库向量维度和索引生成规则保持不变。

验证完成：权限存储不可用场景的模型与凭证边界测试，以及隔离 PostgreSQL、Formance 环境下 `modelaccess` 和 `httpapi` 两包 race 回归。历史别名结果读取的访问令牌过期、撤销、产品停用和成员移除测试通过。测试未调用真实供应商或修改生产账本。
