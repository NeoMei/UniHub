# UniHub v0.4.43

产品接入与部署工具对显式 `refresh_tokens: true` 的客户端设置 Casdoor `refreshExpireInHours: 720`，与既有 30 天刷新 family 一致；access token 保持 1 小时。默认或 false 不启用刷新授权，也不新增刷新期限。

Bootstrap 对现有应用的策略不符返回校验错误，不自动 UPDATE。产品 CLI 的已有审阅计划、明确 apply、精确回读和凭据保护能力保留。旧刷新凭据保留原到期日；配置变化不延长已签发的刷新凭据。

补回两项密码变更失败回归：删除浏览器会话或完成截止时间落库失败时，保持 pending 并拒绝浏览器会话。Go 生产身份逻辑没有改变。

发布范围为更新后的接入、部署工具及标准完整分发资产。现有服务不因本次工具包发布自动重启或切换；现有应用策略、凭据、支付、钱包与账本不作变更。全新安装仍须按部署文档配置并验收，不将工具包发布视为线上迁移已经完成。

验证：原修复在全新隔离 PostgreSQL 上通过 27 项 Python 测试与 identityapi race 44 项顶层测试，均无跳过；发布验证包含版本一致性、打包边界、完整附件内容及消费源码检查，结果另按本次发布收据记录。未调用真实供应商、真实付款或生产数据库。
